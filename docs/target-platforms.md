# Comprehensive Guide: Platforms with Data Export Capabilities for Data Analysis

## Overview

When building a privacy-focused, offline-first data analytics application using **Tauri** and **Rust**, leveraging platform data exports is the most reliable approach. Since user data is downloaded directly from services via official compliance features (GDPR, CCPA) or local application state files, your application avoids API rate limits, OAuth overhead, and API access restrictions.

Rust provides exceptional performance for parsing large JSON files, processing high-volume CSVs, querying SQLite databases, and regex-parsing unstructured text logs. Combined with Tauri's lightweight desktop shell, you can process gigabytes of personal social media archives locally with minimal memory footprint.

## 🌟 Tier 1: Primary Core Targets (High-Priority Platforms)

These eight platforms form the primary foundation for your social and media analysis application. They offer robust data export features and rich personal interaction histories.

| Platform             | Export Access Method                                               | File Formats Provided                    | Extractable Data & Analytical Potential                                                                                                                                                                                                                       |
| :------------------- | :----------------------------------------------------------------- | :--------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Telegram**         | Telegram Desktop > Settings > Advanced > Export Telegram Data      | `JSON`, `HTML`                           | Complete message history for direct messages, group chats, and public/private channels. Includes media metadata, stickers, reaction counts, poll responses, and timestamped user interactions. Ideal for NLP, sentiment analysis, and chat frequency metrics. |
| **WhatsApp**         | Individual/Group Chat > Settings > Export Chat                     | `.txt` (with optional media attachments) | Plaintext file containing timestamped logs of messages, sender names, system events, and media references. Easily parsed via regex or parser combinators (`nom` in Rust).                                                                                     |
| **X (Twitter)**      | Account Settings > Download Archive                                | `JSON` + `HTML` (packaged in ZIP)        | Exhaustive archive containing all tweets, retweets, quote tweets, direct messages (DMs), likes, bookmarks, followers, following, blocked users, ad engagement history, and demographic tags. Excellent for sentiment analysis and network graphs.             |
| **Google Ecosystem** | Google Takeout (`takeout.google.com`)                              | `JSON`, `CSV`, `HTML`, `ICS` (ZIP)       | Multi-service export: YouTube, Chrome history, My Activity, Fit, Keep, Calendar, Photos metadata, Access Log. Mail/Drive skipped in v1. Multi-part ZIPs supported.                                                                                              |
| **Instagram**        | Accounts Center > Your Information and Permissions > Download Info | `JSON` or `HTML`                         | Direct messages, posts, stories metadata, comments, likes, saved posts, guide items, search history, close friends list, and profile changes over time.                                                                                                       |
| **TikTok**           | Settings > Account > Download Your Data                            | `JSON` or `TXT`                          | Video view history, like history, comment archive, direct messages, favorite videos/sounds, profile details, and behavioral attributes.                                                                                                                       |
| **Spotify**          | Account > Privacy Settings > Download Your Data                    | `JSON`                                   | **Extended Streaming History**: Full lifetime play records including track name, artist, album, exact timestamp, millisecond duration played, IP address, and platform device. Also includes playlists, library, and audio interactions.                      |
| **YouTube**          | Google Takeout (`takeout.google.com`)                              | `HTML`, `CSV` (ZIP)                      | Watch history, search history, playlists, video comments, subscriptions. HTML My Activity–style histories are the common Takeout format.                                                                                                                               |

## 💬 Tier 2: Secondary Messaging & Communication Platforms

| Platform             | Export Access Method                                  | File Formats Provided                      | Extractable Data & Analytical Potential                                                                                                                                                                                                                                 |
| :------------------- | :---------------------------------------------------- | :----------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Discord**          | User Settings > Privacy & Safety > Request Data       | `JSON`                                     | Complete archive of messages sent across all direct messages (DMs), group DMs, and Discord servers (guilds). Includes friend lists, server memberships, user activity logs, and voice channel attendance.                                                               |
| **Signal**           | Desktop/Mobile Local Backup                           | Encrypted SQLite Database                  | Raw database file containing message logs, contact keys, and media references. Decrypted locally using the user's 30-digit passphrase via open-source tools or custom Rust decryption routines.                                                                         |
| **Slack**            | Workspace Administration > Export Data                | `JSON`                                     | Message histories for public channels (and private channels/DMs for enterprise exports). Includes user profile details, reaction emojis, threaded conversations, and integration logs.                                                                                  |
| **iMessage (Apple)** | macOS System Storage                                  | `SQLite DB` (`~/Library/Messages/chat.db`) | Direct access to the macOS local SQLite database. Contains every iMessage and SMS sent/received, timestamps (Apple epoch nanoseconds), contact identifiers, attachment metadata, and message status (read/delivered). Can be queried directly in Rust using `rusqlite`. |
| **Skype**            | Skype Privacy Settings / Export Web Page              | `JSON`                                     | Complete historical chat transcripts, call logs, contacts, and voicemail metadata.                                                                                                                                                                                      |
| **Element / Matrix** | Room Settings > Export Chat                           | `JSON`, `HTML`, `TXT`                      | Decentralized chat room logs, state events, member history, and timestamped event IDs.                                                                                                                                                                                  |
| **Viber**            | Settings > Calls and Messages > Email Message History | `CSV` / `TXT`                              | Chat logs formatted as delimited files containing timestamps, phone numbers, and message content.                                                                                                                                                                       |
| **Line**             | Chat Settings > Export Chat History                   | `.txt`                                     | Plaintext message logs including timestamps, sender names, and sticker metadata.                                                                                                                                                                                        |
